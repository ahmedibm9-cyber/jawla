## Acceptance Criteria

### AC 1: Negative stock prevention
- Rep tries to sell > van stock -> UI shows bilingual error modal -> no invoice created

### AC 2: Duplicate invoice prevention
- Double-click Submit -> second submit shows \
duplicate\ error -> no double-create

### AC 3: Credit limit enforcement
- Customer exceeds credit limit -> UI shows balance/limit warning -> blocks or warns per config

### AC 4: Sequential invoice numbering
- Create 3 invoices -> numbers are SALESINVOICE-XX-YYYY-001, 002, 003 per company

### AC 5: Atomic invoice+stock+cashbox rollback
- Force stock decrement failure mid-transaction -> UI shows rollback toast -> cashbox/invoice/stock unchanged

### AC 6: Purchase request dual review
- Purchasing approves without Sales approval -> blocked
- Sales approves without Purchasing approval -> blocked
