## Story

**As a** Purchasing Manager
**I want** A Purchase Order automatically created when I approve a purchase request
**So that** The supplier gets a formal PO, stock is allocated, and the request is closed

---

## Acceptance Criteria

### AC 1: PurchaseOrderService::createFromPurchaseRequest(PurchaseRequest )
- Creates PurchaseOrder + PurchaseOrderItem in DB::transaction()
- Uses StockService to allocate/reserve stock
- Wraps in DB::transaction()

### AC 2: Called from PurchaseRequestResource::purchasing_approve action AFTER status update
- Action updates status to purchasing_approved, then calls PurchaseOrderService::createFromPurchaseRequest()

### AC 3: PO number sequential per company
- Includes supplier, product, qty, price, delivery date, terms
- PO number sequential per company: PO-GPC-2026-00001

### AC 4: Feature test: rep submits -> sales approves -> purchasing approves -> PO exists with correct data

### Integration Point

In PurchaseRequestResource.php purchasing_approve action (line 128-134), AFTER ->update([...]), call:
`
app(PurchaseOrderService::class)->createFromPurchaseRequest();
`

### PO Number Format
PO-{company_abbr}-{YYYY}-{#####} e.g., PO-GPC-2026-00001 using NumberSequenceService
