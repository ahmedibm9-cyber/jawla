# Brainstorm Intent — Jawla Enhancements

## Selected Directions

### 1. Analytics & Documents (Phase 1)

- Dashboard with Chart.js (layout presets + drag-drop)
- Report templates (user-provided, on-demand generation)
- Export: PDF + Excel + CSV (screen-optimized + print-ready)
- Native OS share sheet

### 2. Geospatial (Phase 2)

- Geofenced check-in (100m default, configurable per customer)
- Route optimization (smart suggestion + manual override)
- Heatmap (sales, visits, customer density — all toggleable)
- Offline map auto-caching

### 3. Offline & Mobile (Phase 3)

- Silent background sync
- Capacitor native app
- Photo + GPS verification for all photos
- Offline map tile caching

### 4. Security (Phase 4)

- Biometric auth (login + all critical actions)
- Device fingerprinting (soft flag unknown devices)

## Constraints

- No AI/ML (no API keys, no AI slop)
- No WhatsApp API integration
- No barcode scanning
- Sleek, minimal, professional design system
- Free/open-source only
