# Story CG4.3 -- Odoo Connector MVP

**Status:** ready-for-dev
**Epic:** CG4 -- API + ERP Ecosystem
**Estimated effort:** Large (~2-3 weeks)
**Blocked by:** CG4.1, CG4.2
**Labels:** odoo, erp, connector, p2

---

## Story

**As a** mid-market distribution customer  
**I want** Jawla to sync with Odoo without custom one-off code  
**So that** field execution and back-office accounting stay aligned.

---

## Acceptance Criteria

- Odoo connector supports customer/product import and invoice export MVP.
- Sync ownership rules are documented (which system wins for which fields).
- Failures are observable and replayable.
- Demo environment proves end-to-end sync on seeded data.
