## Story

**As a** QA Engineer
**I want** Playwright tests that verify B0 Design System compliance on every page
**So that** Skeleton loaders, empty states, consequence modals, RTL support never regress

---

## Acceptance Criteria

### AC 1: Skeleton loaders on every list page
- Every list page (Home, Customers, Stock, Quotations, Orders, Visits, etc.) shows skeleton while loading

### AC 2: Empty states with actions
- Every empty list shows x-ds-empty with icon, message, and action button

### AC 3: Consequence modals on all financial actions
- Invoice, Payment, Return, Expense, Quotation price confirm, Proforma create, Purchase Offer -> all use x-ds-modal with consequence text

### AC 4: RTL/LTR flip
- Switch locale to ar -> all pages render RTL correctly (flex direction, margins, icons)

### AC 5: 6-state buttons
- All interactive elements show: normal, hover, focus, active, loading, disabled

### AC 6: 60/30/10 color compliance
- Backgrounds are #FFFFFF/#F5F5F4, text is #1F2937, accent is #9B1C31
- Success #16A34A, Warning #D97706, Danger #DC2626, Info #2563EB

## Technical Details

### File: tests/e2e/b0-states.spec.ts

### Key Test Patterns

`	ypescript
// Skeleton
await page.goto('/app/customers');
await expect(page.locator('x-ds-skeleton')).toBeVisible();

// Empty state
await page.goto('/app/stock?search=nonexistent');
await expect(page.locator('x-ds-empty')).toBeVisible();
await expect(page.locator('x-ds-empty >> text=Add Customer')).toBeVisible();

// Modal
await page.click('button:has-text(\
Submit\)');
await expect(page.locator('x-ds-modal')).toBeVisible();
await expect(page.locator('text=An invoice of X will be created')).toBeVisible();

// RTL
await page.goto('/app?locale=ar');
await expect(page.locator('html')).toHaveAttribute('dir', 'rtl');
await expect(page.locator('.tab-bar')).toHaveCSS('flex-direction', 'row-reverse');

// Color
const btn = page.locator('button.btn-primary');
await expect(btn).toHaveCSS('background-color', 'rgb(155, 28, 49)'); // #9B1C31
`
