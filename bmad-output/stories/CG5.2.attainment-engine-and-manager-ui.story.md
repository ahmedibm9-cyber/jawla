# Story CG5.2 -- Attainment Engine and Manager UI

**Status:** ready-for-dev
**Epic:** CG5 -- Sales Targets & Attainment
**Estimated effort:** Medium (~1 week)
**Blocked by:** CG5.1
**Labels:** targets, analytics, dashboard, p2

---

## Story

**As a** sales manager  
**I want** to see actual vs target by rep and period  
**So that** I can coach and intervene with data.

---

## Acceptance Criteria

- Attainment is computed from persisted invoices, payments, and visits only.
- Manager UI supports period filter and rep filter.
- Progress bars / status chips show under-target vs on-track vs achieved.
- Values reconcile with source reports.
